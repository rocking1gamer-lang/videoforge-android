# VideoForge browser MVP

Open `index.html` from the `web/` folder in a browser, or publish the `web/` folder with GitHub Pages.

Current prototype:
- Prompt → local scene plan
- Modern explainer visual style selector
- Timeline and scene navigation
- Phone/browser speech synthesis with selectable voices
- No API key and no server required for the prototype

Planned next:
- Real script generation
- Deterministic scene timing
- Word-level narration sync
- Downloadable WAV/MP3 narration
- SVG/icon/chart animation
- MP4 rendering pipeline
- Android/Termux packaging
